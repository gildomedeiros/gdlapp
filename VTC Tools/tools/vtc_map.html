SX footage timing

Log time = recording start + playback + correction. Positive correction moves the log time later. If the result is 10 hours out, change Metadata clock. A recording-start override below accepts a full date/time (Brisbane if no timezone). Metadata and originals are read only.

Timestamp selection

Choose a video and enter its playback time, or use a log timestamp. Leave all rows blank for the full session. Each row starts at the last accepted GPS receipt at or before the timestamp. Times without an offset use Brisbane (+10:00).

Local metric map, following VT Tools. The FOV fan uses estimated width = distance × wideFrameFactor / current readback zoom, centred on logged camera heading. Its far-edge arrow shows observed camera pan direction; surfer arrows use consecutive full-log GPS fixes. Stale zoom or heading shows the last-known fan in red; fresh data shows green.
